# 养牛资讯与每日小知识

本功能适用于 hm 鸿蒙 APP 和 wx 微信小程序。入口在总览、管理页的“养牛资讯”。

## 已实现

- 新闻：按健康防疫、饲养营养、环境管理、行业动态、市场行情分类；支持搜索、详情、原文链接与收藏。
- 小知识：12 张项目整理的养殖知识卡，每天按北京时间稳定推荐一张，同一天刷新不会重复生成推送消息。
- 消息：站内消息列表、未读数量、阅读后标记、全部已读；首次推荐最多 3 条新闻，后续只提醒新发现的订阅内容。
- 订阅：新闻提醒、每日知识开关，以及关注分类；设置保存在当前设备。
- 收藏：本机最多 100 条，保存内容快照；内容不在当前新闻列表中时仍可读取收藏。
- 缓存：网络异常时保留上次内容，并显示更新失败与缓存状态。
- 联动：从详情带入问题到 AI 助手或专家咨询，提交问答仍由用户主动执行。

## 内容来源

后端每 30 分钟检查两个公开栏目，客户端在相关页面打开时及前台每分钟同步一次。

1. 农业农村部畜牧兽医局：<https://xmsyj.moa.gov.cn/>
2. 全国畜牧总站：<https://www.nahs.org.cn/>

新闻保存原始标题、发布机构、发布日期和原文地址，不将抓取时间冒充发布时间，也不生成虚构行情数值。
新闻详情是索引和阅读提示，完整报道与附件以原发布页为准；小程序通过复制链接提供原文入口。
小知识由项目自行整理，包含饮水、换料、饲料储存、反刍、蹄部、热应激、隔离、红外测温、犊牛、传感器、粪污和巡检记录。
知识卡署名为“数牧增效养殖知识库”，并附延伸阅读来源，不冒充新闻机构发布的原文。

采集器只处理白名单来源的日期型文章链接，过滤无关禽猪新闻、外站链接、未来日期和截断标题；重复地址使用稳定编号去重。
来源失联或栏目结构变化时显示该来源不可用，保留数据库中的历史内容。Windows 下采用系统根证书验证官方站点证书；其他系统使用 JVM 默认信任库，始终保留证书与主机名校验。

## 接口与存储

- `GET /api/mobile-support/news/feed`：最近 150 条内容、来源状态、每日推荐编号和北京时间日期。
- `GET /api/mobile-support/news/articles/{id}`：单条详情。
- MySQL 表：`cattle_article`、`cattle_news_source`，由后端 `schema-mysql.sql` 创建。
- 后端校验：`mvn test -Dtest=CattleNewsParserTest,ApiKeyAccessPolicyTest`。
- 客户端状态校验：`node scripts/test-news-state.cjs`；小程序类型检查使用 wx 目录下的 TypeScript。

## 推送范围

当前提供的是应用内资讯推送与未读提醒。页面关闭、应用进程退出后不会继续显示系统通知。
锁屏远程推送需要鸿蒙 Push Kit 项目、证书与设备令牌；微信订阅消息需要真实小程序的模板、服务端凭据、用户 openid 与用户主动订阅授权。这些资源尚未配置，当前没有发送此类消息。
订阅开关不会自动向第三方专家、短信或其他联系人发送内容。

新增源码和界面应在最终确定版本后重新导出到软著申请材料；已有导出文件仍是旧版本快照。
